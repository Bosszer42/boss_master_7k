# รูปแบบไฟล์สำหรับ Writer Workspace

Writer Workspace ใน BOSSMASTER AI CHAT & BATCH 0.3.0 ไม่มีคีย์เวิร์ด แท็ก กฎเว็บไซต์ หรือ Master Prompt ฝังอยู่ในตัวติดตั้ง ผู้ใช้ต้องเข้าสู่ระบบแล้วกด **อัปโหลดข้อมูลงาน** ด้วยตนเอง

## ไฟล์ที่รองรับ

- TXT และ Markdown: ใช้เป็น Prompt หรือ Rule ตามชื่อไฟล์
- CSV: อ่านแถวข้อมูลจากตาราง
- JSON: รองรับโครงสร้างแบบกำหนดชื่อกลุ่ม
- XLSX/XLSM: อ่านทุก Sheet
- ZIP: อ่านเฉพาะไฟล์ชนิดที่รองรับ ไม่แตกไฟล์ลงเครื่อง ไม่รันไฟล์ และป้องกัน Path Traversal

ขนาดรวมต่อการนำเข้าหนึ่งครั้งไม่เกิน 25 MB และข้อมูลหลังประมวลผลต่อชุดไม่เกิน 12 MB หากใหญ่กว่านี้ให้แบ่งเป็นหลายชุด

## ชื่อคอลัมน์ที่ระบบรู้จัก

ระบบตรวจชื่อภาษาอังกฤษและภาษาไทยโดยไม่สนตัวพิมพ์เล็ก/ใหญ่:

| ประเภท | ชื่อคอลัมน์ตัวอย่าง |
| --- | --- |
| เว็บไซต์ | `site`, `website`, `domain`, `เว็บไซต์`, `เว็บ` |
| คีย์เวิร์ด | `keyword`, `keywords`, `key`, `focus`, `focus_keyword`, `คีย์เวิร์ด`, `คีย์`, `โฟกัส` |
| แท็ก | `tag`, `tags`, `tag_set`, `แท็ก` |
| หมวดหมู่ | `category`, `categories`, `หมวดหมู่`, `หมวด` |
| Prompt | `prompt`, `system_prompt`, `instruction`, `คำสั่ง`, `พรอมต์` |
| กฎ | `rule`, `rules`, `validation`, `validator`, `กฎ` |
| โหมด | `mode`, `writing_mode`, `โหมด` |

หลายค่าในช่องเดียวคั่นได้ด้วยจุลภาค เซมิโคลอน เครื่องหมาย `|` หรือขึ้นบรรทัดใหม่

## ตัวอย่าง JSON

```json
{
  "site": "example.com",
  "mode": "normal",
  "keywords": ["คีย์หลัก", "คีย์สนับสนุน"],
  "tagSets": [
    {
      "name": "ชุดแท็กหลัก",
      "tags": ["แท็กหนึ่ง", "แท็กสอง"]
    }
  ],
  "categories": ["หมวดหลัก"],
  "prompts": [
    {
      "name": "NORMAL",
      "mode": "normal",
      "content": "คำสั่งการเขียนของโครงการ"
    }
  ],
  "rules": [
    {
      "name": "กฎตรวจผล",
      "content": "ใช้เฉพาะข้อมูลต้นฉบับ"
    }
  ]
}
```

## ความปลอดภัยและการแยกข้อมูล

- ชุดข้อมูลบันทึกหลังอัปโหลดและผูกกับบัญชีที่ล็อกอิน
- Viewer เปิดดูได้แต่ไม่สามารถนำเข้า ลบ บันทึกร่าง หรือเรียก AI
- API Key ยังเก็บด้วย Windows safeStorage เหมือนระบบแชทเดิม
- การ Backup ฐานข้อมูลจะรวมชุดข้อมูลและร่าง Writer เพราะข้อมูลถูกเก็บในฐานข้อมูลผู้ใช้
- ตัวติดตั้ง Source และไฟล์ Release ไม่มีชุดข้อมูลที่ผู้ใช้อัปโหลด

## ขั้นตอนใช้งาน

1. เข้าเมนู **เขียนโพสต์**
2. ระบุชื่อชุดและกด **อัปโหลดข้อมูลงาน**
3. เลือกชุด เว็บไซต์ และโหมด
4. กด **สุ่มจัดชุด** หรือแก้ Focus/Tags/Categories เอง
5. ใส่ข้อมูลต้นฉบับที่ยืนยันแล้ว
6. ตั้ง Validator ตามต้องการ
7. เลือก Provider/Model และกด **เขียนด้วย AI**
8. ตรวจผล บันทึกร่าง และส่งออก
