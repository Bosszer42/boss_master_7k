# BOSSMASTER AI CHAT & BATCH

Windows desktop application for OpenAI/Gemini chat, code workspaces, batch queues, private notes, and a separate Writer Workspace.

Version 0.3.0 adds user-uploaded writing data packs (TXT/MD/CSV/JSON/XLSX/XLSM/ZIP), deterministic keyword/tag/category selection, structured post generation, validation, drafts, and XLSX/CSV/JSON/Markdown export. No WorkPad data, prompts, tags, keywords, or API keys are bundled in the installer.

See [README_TH.md](README_TH.md) and [docs/WRITER_DATA_FORMAT_TH.md](docs/WRITER_DATA_FORMAT_TH.md).
